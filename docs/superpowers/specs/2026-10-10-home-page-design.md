# 首页（进入界面）设计

日期：2026-10-10
项目：激光门
状态：待确认，确认后进入实现

## 1. 背景与目标

现在打开站点根地址直接就是编辑器，缺少一个封面。本次新增一个首页作为站点入口：根地址先给出一屏封面，从封面上的四个入口进编辑器。

首页只做展示与分流，不承担编辑职责。它整屏用 Canvas 绘制，DOM 只留给两个弹窗。

网格为静态铺底，不做缓慢平移：两侧已经有东西在动，背景再动会显得吵。

## 4. 四个入口的行为

| 入口 | 点击后 |
| --- | --- |
| 新建 | 跳到编辑器，空白画布 |
| 打开 | 在首页上先弹出系统的文件选择框，选完跳到编辑器并把存档带过去 |
| 教程 | 首页正中弹出教程窗，内容与编辑器里那份完全一样 |
| 关于 | 首页正中弹出简介窗 |

**「打开」的浏览器限制与绕法**：系统的文件选择框只允许在「用户刚点过东西」的那一刻调用，页面一加载就自动调会被浏览器拒绝。所以「打开」不能在编辑器里自动触发，只能在首页上、点击的那一刻触发。

做法：点「打开」，首页直接把选择框弹出来，读完文件后把内容暂存起来再跳转，编辑器加载时把暂存的内容接过来铺到画布上。

暂存方式：

- 电路正文用会话存储带过去，编辑器读完就清掉。
- 文件句柄沿用项目里已有的那套记忆机制（写进同一个库、同一个键），编辑器启动时本来就会去读，读到的就是刚选的这个文件，后续保存仍直接写回原文件。

## 5. 两侧演示电路

左边演示「转向」，右边演示「分光」，两边都在循环。

左侧：光源朝右发出一束光，走到偏转器后拐向上，点亮上面的灯。

```
▶ ──── ▣        光源 → 偏转器（转向）→ 灯
        │
        ●
```

右侧：光源朝右发出一束光，走到透射器后一分为二，一束继续向右点亮右边的灯，一束拐向上点亮上面的灯。

```
        ●
        │
▶ ──── ▣ ──── ●   光源 → 透射器（分光）→ 两盏灯
```

- 两边各占 6 格宽、5 格高。
- 一格的屏幕边长按可用空间算，钳在 20 到 56px 之间；可用宽度不够放下 20px 一格时，这一侧的演示整组淡出。
- 时间轴：光以每秒 8 格推进，走完主光再走分支；灯在被照到的那一刻亮起；然后停留 1.2 秒；接着整组淡出 0.5 秒、淡入 0.5 秒，从头再来。
- 右侧整体比左侧晚半个周期，避免两边同时亮同时灭。

绘制层次从下往上：网格、激光、灯的光晕、元件本体。激光用八层同心描边叠出连续衰减；灯亮起时颜色按通道从元件蓝混到淡红；光晕用模糊的圆角方框。这几处都读编辑器里同一份配置参数，保证观感一致。

演示是独立写的一小段动画，**不接入编辑器那套电路结算引擎**：引擎是围绕可编辑网格设计的，为了首页这点展示去驱动它，改动面太大，不划算。

## 6. 两个弹窗

教程窗和关于窗都是网页元素，直接套用编辑器里那套弹窗样式，底板、圆角、边框、左上角关闭的叉全部同款。

- 两个窗互斥，开一个另一个自动关。
- 点窗外的暗处不关，只有点那个叉才关。
- 教程窗：内容与编辑器里那份逐字相同，从共用文件里取，两边永远一致；尺寸沿用编辑器那份（宽 520、高 360，内容超出时内部滚动）。
- 关于窗：新写，宽度取 420。内容是项目名、一句话简介、作者、开源地址、在线地址、许可证。

## 7. 窄屏

| 窗口宽度 | 表现 |
| --- | --- |
| 1100px 以上 | 两侧演示都完整显示 |
| 约 800 到 1100px | 两侧演示按可用空间缩小，不压到中间列 |
| 约 800px 以下 | 两侧演示整组淡出，只剩网格与中间那一列 |

淡出不是硬切，在临界宽度前后留一段过渡带，宽度变化时透明度跟着连续变化。

## 8. 代码结构

首页整屏都用画布画，包括标题和四个入口，不写成网页元素。理由：

1. 「教程图标和编辑器里那个一样」只有复用同一段画图标代码才能保证像素一致，而那段代码是画在画布上的。
2. 两侧演示本来就在画布上，标题和入口同处一个坐标系，「不会互相遮挡」可以直接算出来，不依赖样式表。
3. 编辑器里那些槽和按钮本来就是画在画布上、自己算命中区域的，首页跟着这套做法，两个页面的写法一致。

代价：入口的命中区域要自己算，用和画槽同一个办法——一个函数同时给出矩形并负责判定，画和点永远一致。文字不能选中、不能用键盘 Tab 到达，这对一个封面可以接受。

三个共用模块的分工：

| 模块 | 内容 |
| --- | --- |
| `icons.js` | 加号、折角纸、圆圈问号、圆圈惊叹号四个图标的几何；编辑器里齿轮、文件、教程、选中那四个也一并搬进来，图标形状从此只有一个出处 |
| `tutorial-content.js` | 教程正文与它的排版样式，编辑器与首页共用 |
| `handle-store.js` | 文件句柄的记忆：写入与读回，编辑器与首页共用 |
| `config.js` | 新增一段首页专用参数（布局、演示、时间轴、窄屏阈值），与编辑器参数分开成两块，互不干扰 |

图标函数搬家时接口基本不动，只多加一个可选的缩放系数参数，默认值仍是编辑器里那一档，所以编辑器那边的调用点一行都不用改；首页传自己的系数即可。圆圈惊叹号是新画的，用与圆圈问号同一套画法（实心圆面加描边，符号用本色描出），只是把里面的符号换成惊叹号，两个图标并排时视觉重量一致。

首页自己的绘制分四段，各自独立：画网格、画两侧演示、画中间那一列、算入口的命中区域。主循环只调用它们。

## 9. 编辑器要改的地方

只有两处：

1. 入口页跳过来时，编辑器要能接着打开存档：在初始化末尾检查地址标记与暂存内容，有就导入。
2. 给首页腾出地址：编辑器自己的逻辑一行不动。

## 10. 待定项（需用户确认）

1. **标题描边的取色与宽度**：默认方案是深蓝字面配浅色描边（字在浅蓝网格上立起来）。是否改成浅色字面配深蓝描边，或另定描边颜色与宽度，待定。
2. **教程窗正文**：编辑器里那个教程弹窗目前内容区是空的，首页这个同样。先按《基本逻辑》那份文档拟一版草稿，再由用户修改定稿。
3. **关于窗文案**：项目名、简介、作者、开源地址、在线地址、许可证的具体文字，待定。

## 11. 不做

- 首页的缓慢平移背景动画。
- 首页的存档列表（竖栏只在编辑器里有）。
- 首页直接编辑电路。
- 首页接入编辑器的电路结算引擎。
